三、微信内的实际表现

  1. 安卓：多数情况点“立即拨打”直接弹出系统拨号盘。
  2. iPhone：部分微信版本会拦截 tel: 协议，需点右上角“···”
     →“在浏览器打开”（Safari）后再拨号。
  3. 兜底：点“复制号码”，返回拨号盘粘贴拨打。

四、如何更新页面

  1. 本地修改 index.html 与 call.html（两份内容保持一致）。
  2. 在仓库目录执行：
       git add -A
       git commit -m "update: 修改说明"
       git push
  3. GitHub Pages 约 30–60 秒自动重新发布，无需其他操作。

五、注意

  - 该页面为公开可访问，手机号对任何拿到链接的人可见。
  - 仓库需保持 public，否则 Pages 无法免费发布。
  - 若需自定义域名，在仓库 Settings → Pages → Custom domain 中配置，
    并在域名服务商添加 CNAME 记录指向 sc555555.github.io。
