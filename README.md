# 网页拨号页（call）

一个纯静态的单页拨号卡片，扫码或打开链接后可一键呼叫 `176 2716 0160`。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 拨号主页面（GitHub Pages 默认入口） |
| `call.html` | 与 `index.html` 内容一致的副本，方便直接按原文件名访问 |
| `qrcode.png` | 指向本站真实地址的二维码图片 |
| `使用说明.txt` | 部署与使用备忘 |

## 技术说明

- 无依赖、无构建、无后端，单个 HTML 文件即可运行。
- 拨号按钮使用 `tel:` 协议；微信内置浏览器可能拦截，页面已提供「复制号码」
  与「在浏览器打开」两条兜底路径。
- 部署方式：GitHub Pages（`main` 分支根目录）。

## 本地预览

直接用浏览器打开 `index.html` 即可。
